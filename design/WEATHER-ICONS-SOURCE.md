# Weather Icon Sources

VectorDrawables in `app/src/main/res/drawable/`:
- `ic_weather_clear.xml`: Sun outline & rays glyph, inspired by Material Symbols (Apache 2.0).
- `ic_weather_fair.xml`: Sun behind cloud glyph, inspired by Material Symbols (Apache 2.0).
- `ic_weather_cloud.xml`: Standard cloud glyph, inspired by Material Symbols (Apache 2.0).
- `ic_weather_fog.xml`: Cloud with horizontal fog lines, inspired by Material Symbols (Apache 2.0).
- `ic_weather_drizzle.xml`: Cloud with drizzle drops, inspired by Material Symbols (Apache 2.0).
- `ic_weather_rain.xml`: Cloud with rain slashes, inspired by Material Symbols (Apache 2.0).
- `ic_weather_snow.xml`: Cloud with snow flakes, inspired by Material Symbols (Apache 2.0).
- `ic_weather_storm.xml`: Cloud with lightning bolt, inspired by Material Symbols (Apache 2.0).

All drawables use `#FFFFFFFF` fill color to allow runtime tinting with `palette.gold`.
