One recording for Fajr, Dhuhr, Asr, Maghrib, and Isha. The file that ships on Play is `app/src/main/res/raw/athan_saudi.mp3`. There is no second copy in `audio/`.

Personal use on Mutaz's wall. Replace before strangers install from Play. Tags do not give a rights clearance.

## athan_saudi.mp3

Display name is Saudi athan. File Mutaz picked (was `400685.mp3`). ID3 tags point at IslamWeb, 2013.

- Duration: 3:05
- Format: MP3, 128 kbps, 16 kHz stereo
- Stated tags: `www.islamweb.net`

Same file plays for all five prayers.
