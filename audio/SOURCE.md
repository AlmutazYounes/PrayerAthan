# Athan audio sources

Makkah / Maki (الحرم المكي) recordings for the wall clock. Masters stay in this folder. The APK copies them to `app/src/main/res/raw/` as `athan_fajr.mp3` and `athan_standard.mp3`.

Personal use, replace before strangers install from Play. The pages below allow download. They do not give a clean rights clearance from the Haramain muezzins. Fine on Mutaz's wall. Not fine to ship on Play as if we own the recordings.

## fajr.mp3

Fajr athan from Masjid al-Haram, 13 November 2009. Source title is Fajr, so it should include الصلاة خير من النوم. Confirm by ear when wiring playback. Muezzin is not named on the item page.

- Duration: 4:09
- Format: MP3, 128 kbps, 44.1 kHz stereo
- Derived from the Archive.org 512kb MPEG-4 (`13thNov09FajrAzan_512kb.mp4`), audio only
- Item: https://archive.org/details/MakkahAzan
- File: https://archive.org/download/MakkahAzan/13thNov09FajrAzan_512kb.mp4
- Stated license on that item: public domain, `http://creativecommons.org/licenses/publicdomain/`
- Uploader: Maahir, 2009

That PD tag is the uploader's claim. A 2009 live Haram recording is likely still copyrighted. Use at home. Replace before strangers install from Play.

Do not replace this file when swapping the standard athan.

## standard.mp3

Standard athan (Dhuhr, Asr, Maghrib, Isha). No Fajr addition. Isha from Masjid al-Haram by Ali ibn Ahmad Mala (علي بن أحمد ملا), 18 Muharram 1439. Whisper on the mid-file heard حي على الصلاة then حي على الفلاح, then closing الله أكبر. It did not hear الصلاة خير من النوم.

- Duration: 3:22
- Format: MP3, 128 kbps, 44.1 kHz stereo
- Source audio: AAC 96 kbps stereo in the Archive.org MP4, then encoded to this MP3
- Item: https://archive.org/details/0314zzzz181439
- File: `0314 ZZZZ  أذان العشاء للمؤذن الشيخ علي بن أحمد ملا اليوم الأحد 18 محرم 1439 - من الحرم المكي.mp4`
- Download: https://archive.org/download/0314zzzz181439/
- Stated license on that item: none. Uploader `alfirdwsiy2018`, 2019.
- Provenance note: the MP4 handler is `IsoMedia File Produced by Google`. This is an Archive.org copy of a YouTube-origin Haram Isha, not a file we ripped from YouTube ourselves. PLAN.md wants that written here.

Same rule. Personal use, replace before strangers install from Play. We do not own Haramain copyright.

## What we skipped

Three extra Dhuhr–Isha choices were pulled from the picker and deleted: Haram Isha 13 Nov 2009 (`isha_2009.mp3`), Ali Ahmed Mullah 12 Nov 2009 (`isha_mullah_2009.mp3`), and Haram Friday 13 Nov 2009 (`friday_2009.mp3`). All three were the same Archive.org `MakkahAzan` item as Fajr. Mutaz asked for a shorter list. Ali Mala stays as the only standard choice.

The previous `standard.mp3` was the GitHub Kiwifu file `Ali_Ibn_Ahmad_Mala_-_HQ_(علي_بن_أحمد_ملا).mp3` (4:04, 128 kbps, haii3alslah.com tags). It is a real Ali Mala recording, and it is not a byte copy of `fajr.mp3`. Whisper on 2:00–3:40 still heard the Fajr line (تخير من النوع / الصلاة خير من النوم) twice. Mutaz heard that on Dhuhr through Isha. Replaced.

That same repo's numbered Ali Mala files (`Ali_Ibn_Ahmad_Mala_1` through `_6`) and `Adhan_Fajr_Al_Haram_Al_Maki` are about 16 kbps. Too thin for a room speaker.

`Ali_Ibn_Ahmad_Mala_HQ.mp3` (ASCII name, 3:18) is a different 128 kbps file. Not used. The labeled Isha above is the one that proved it was not Fajr.

Wikimedia Commons has a CC BY 3.0 Maghrib clip from the Haram (25 Feb 2012, 3omar Faruq). It is five minutes of waiting in the courtyard, not a clean athan file.

Madinah Fajr from the same `MakkahAzan` item stays out. The wall is Makkah athan only.
